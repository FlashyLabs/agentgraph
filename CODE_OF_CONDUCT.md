# Code of Conduct

This repository is part of the Gord & Flashy estate and follows its standard of
conduct: be direct, be accurate, be kind. Disagree with the work, never with the
person. Report what happened, including when it is worse than expected — and
expect the same courtesy when you are the one who made the mistake.

Harassment, discrimination and personal attacks are not tolerated in issues,
pull requests, reviews or any other channel this project uses. A maintainer may
remove content and restrict participation to keep the project usable for
everyone.

Concerns go to the address in `SECURITY.md` (with the same caveat noted there
about confirming the address), or privately to the repository's accountable
owner.
